# かまたん（鎌ケ谷市マスコットキャラクター）デザイン使用に関するメモ

確認日: 2026-10-16

## 出典

- デザイン使用について: https://www.city.kamagaya.chiba.jp/kamatan/request/index.html
- 申請方法: https://www.city.kamagaya.chiba.jp/kamatan/request/request03.html
- 鎌ケ谷市マスコットキャラクター「かまたん」デザイン等使用取扱要綱、デザイン等マニュアル（第4版）

## 要点

- かまたんのデザインは鎌ケ谷市が所有し、使用には**市長の承認（申請）が必要**。使用料は無料。
- 「個人的に、または家庭内等で楽しむために使用する場合」は申請不要だが、
  「ホームページやポスターなどにかまたんのデザインを掲載し、公共に掲示する場合」は申請が必要と明記されている。
  → Web 公開する本ゲームでの公式画像使用は申請対象と解釈する。
- 縦横比の変更、色の変更、反転、一部の改変など、イメージを損なう改変は禁止。
- 承認期間は使用開始から 1 年経過後最初の 3 月 31 日まで（更新あり）。承認後は完成物（または写真）の提出が必要。
- 問い合わせ: 鎌ケ谷市 市民生活部 農業振興課 かまたん担当（電話 047-445-1233）

## 本アプリの対応

- 公式画像は**使用していない**（`src/config/character.ts` の `imageSrc` は `null`、`officialImageApproved` は `false`）。
- 案内役は汎用の方位磁針アイコン（`src/components/mascot/Guide.tsx`）。かまたんに似せたキャラクターは描いていない。
- 名前「かまたん」と「〜たん」口調のセリフはテキストとして使用。承認を得る際はセリフの扱いも確認する。
- 承認を得たら: 承認済み画像を `public/images/` に置き、`CHARACTER.imageSrc` と `officialImageApproved` を更新する。
  画像は加工しない。必要に応じて「鎌ケ谷市マスコットキャラクターかまたん」の併記と承認番号の表示を行う。
